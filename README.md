# 🧠 Sentence Construction Tool

An interactive **Sentence Construction Tool** built with **React**, **Vite**, **Tailwind CSS**, and **TypeScript** (optional), as part of the CA MONK Frontend Internship Assignment.

## 📌 Project Overview

This application presents users with sentences containing blank spaces and a set of word options. The goal is to drag-and-drop or click the correct words to fill in the blanks. A timer counts down from 30 seconds per question. At the end of the quiz, users receive a score with feedback on their performance.

## 🛠️ Features

- 🧩 Fill-in-the-blanks with 4 selectable word options.
- 🔁 Unselect a word by clicking the filled blank.
- ⏱️ 30-second countdown timer for each question.
- 🔄 Auto-navigation to the next question after timer ends.
- ✅ "Next" button is disabled until all blanks are filled.
- 🔗 Fetches data from a local **JSON Server**.
- 📊 Feedback screen with:
  - Score out of 10
  - Highlighted correct and incorrect answers
